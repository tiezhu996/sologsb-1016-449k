# 声场 · 广播剧台词与音效提示编辑器

一个离线优先的广播剧制作台，使用 Vue 3、Vite、TypeScript 和 Naive UI 从零实现。项目按场次管理角色台词、情绪、语速、音效素材与转场提示；提示顺序改变后自动重算时长，并检查角色撞场、音效引用缺失和场次超时。

## 功能

- 场次与提示项增删改、拖动排序、场次上下移动。
- 根据台词字数、语速、标点和素材时长实时估算总时长。
- 角色撞场、缺失音效引用、场次超限实时检查与一键定位。
- **补丁式待确认区**：每次编辑在本地 diff 成按台词/音效定位的补丁，补丁记录 `baseRevision`（基于的稿次），接受或退回只三方合入该补丁涉及的内容，不再整份覆盖。
- **冲突并列选定**：编剧与导演两边改了同一条内容时不覆盖，弹窗并排展示基准稿、补丁方版本、当前草稿版本，导演逐项选定后才能继续；退回时同样适用。
- **检查点与幂等重试**：草稿、补丁队列、冻结版本分三个 `localStorage` 分区保存；多分区写入先落检查点，写入失败自动回滚并保留原稿与检查点，重试同一批补丁不会重复生效。
- **旧稿迁移**：只有整份前后稿快照的旧版数据，首次打开自动重放并拆成补丁继续使用。
- 撤销、重做、快捷键保存和自动保存，刷新或离线不丢草稿。
- 冻结不可变制作版本，生成并下载纯文本制作稿。
- Service Worker 运行时缓存，已打开过的生产页面可离线访问。

## 技术栈

- Vue 3 + Composition API
- Vite 6
- TypeScript
- Naive UI

## 本地开发

```bash
npm install
npm run dev
```

开发服务器只绑定在本地端口 `5173`，这是开发工具默认端口，不包含任何宿主映射。容器生产环境仅监听 `80`。

## 生产构建

```bash
npm install
npm run build
npm run preview
```

构建结果位于 `dist/`。

## Docker

```bash
docker build -t sologsb-1016 .
docker run --rm -p 10016:80 sologsb-1016
```

容器使用 nginx 监听 `80`，并通过 `try_files` 支持前端路由刷新。宿主端口映射由部署编排负责，源码和 Dockerfile 均未写死宿主端口。

## 数据与离线说明

数据保存在当前浏览器的 `localStorage` 中，不会上传到服务器，并按用途分成四个分区：

| 键 | 内容 |
| --- | --- |
| `sologsb-1016-studio-draft-v2` | 当前工作草稿与单调稿次 `revision` |
| `sologsb-1016-studio-patches-v2` | 待确认/已处理补丁队列，每条带 `baseRevision` |
| `sologsb-1016-studio-frozen-v2` | 冻结的只读制作版本 |
| `sologsb-1016-studio-meta-v2` | 当前整理身份（编剧/导演）与迁移提示 |

写入前会在 `sologsb-1016-studio-checkpoints-v2` 留存最近 5 个检查点；保存失败时按检查点回滚并保留原稿，可在「检查点」页签手动恢复。旧版（v1，整份前后稿快照）数据首次打开时自动迁移为补丁，原数据备份在 `…-v1-migrated-backup`。Service Worker 缓存生产页面与已访问的静态资源；录音、音效素材本身不在本项目中，制作稿只保存素材引用路径。
